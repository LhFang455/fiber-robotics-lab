# 光纤机器人传感仿真实验室 · 用户指南

本指南按“启动 → 界面 → 逐页说明 → 演示功能 → 常见问题”的顺序，介绍网站的主要功能与操作方式。

## 1. 这是什么

这是一个本地运行的 Streamlit 教学演示网站，用来展示**光纤传感 + 机器人感知**的完整链路：

光纤传感（抓取、触觉、足底、形状、健康）→ 光纤解调（波长读取、温补、故障隔离）→ 状态估计（CoP、曲率、异常位置）→ 控制与任务（命令输出、报告）。

所有模型都是可解释的解析教学模型，页面会同时给出“真实量”和“反演量”，方便对比。它不是商业产品，也不替代真实硬件标定。

## 2. 快速开始

### 2.1 环境要求

- Python 3.10+；本机已验证 macOS 26.6.2（Apple Silicon）与 Python 3.13.9。Windows 与 Linux 具备运行条件，但尚未在真实机器完成验收。
- 依赖：`numpy`、`plotly`、`streamlit`、`pytest`（测试用）
- 虚拟环境：可使用任意 Python 虚拟环境工具；差异仅在创建和激活方式，激活后的安装、启动和测试命令相同。

### 2.2 安装与启动

以下以 Python 内置 `venv` 为例，给出从下载到启动的完整命令。若使用其他虚拟环境工具，只需按该工具的方式创建并激活环境，再执行对应代码块中的安装与启动命令。

macOS/Linux：

```bash
git clone https://github.com/LhFang455/fiber-robotics-lab.git
cd fiber-robotics-lab
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows PowerShell：

```powershell
git clone https://github.com/LhFang455/fiber-robotics-lab.git
cd fiber-robotics-lab
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。如果没自动打开，手动访问这个地址即可。

环境激活后，安装与启动命令在各平台一致。

### 2.3 先跑一遍推荐路径

1. 点侧边栏“演示预设（恢复公共参数）”，恢复公共测量条件；各页局部参数需用对应的重置按钮恢复；
2. 回到 **① 系统总览**，在“引导式实验路线”选择六条路线之一；六条路线共同覆盖②至⑦的全部内部实验；
3. 阅读每一步的操作和预期观察，点击“进入第 N 步”跳转；完成观察后再主动勾选；
4. 按所选路线完成页面产物，并下载“当前路线学习记录”。路线勾选仅记录学习进度，不判断实验是否正确。

页面底部有“下一步 →”按钮，可以按推荐路径直接跳转。

## 3. 界面总览

### 3.1 侧边栏（左侧固定栏）

- **← 返回主页**：无论你在哪个页面，点它回到 ① 系统总览；
- **快速模块导航**：下拉选择任一领域实验室即可直接跳转；进入领域后再用内部标签选择实验；
- **公共光学与测量参数**：温度变化、波长噪声、零点漂移、采样率、模拟失效通道、复装工况、随机种子，所有页面共用；
- **演示预设（恢复公共参数）**：只把上方公共参数恢复为推荐值，不重置各页局部参数、手部姿态或任务进度；
- **平滑过渡动画（2D/3D 手）**：默认开启，手部动作会平滑过渡；关闭后直接跳变，适合快速调试参数。

> 提示：随机种子让同一参数下的结果可复现，适合做演示和对比实验。

### 3.2 两层导航顺序（推荐按这个顺序体验）

1. **① 系统总览**：六条引导式实验路线、领域目录、系统架构示意、当前配置和感知链说明；
2. **② FBG 基础与解调**：弯曲标定与诊断；解调与实验任务；
3. **③ 手部抓取与触觉**：二维抓取；三维抓取；材质识别；
4. **④ 足底感知与装配**：平衡与步态；装配校验；
5. **⑤ 形状与结构监测**：连续体形状；结构健康；
6. **⑥ 分布式光学与数据**：分布式感知；偏振与干涉；FBG-SimPlus 数据兼容；
7. **⑦ 电子皮肤与多模态感知**：三轴触觉单元；FBG 光学皮肤；稀疏压力重建；动态滑移与多模态。

顶层标签只代表领域。原有实验没有删除，均放入对应领域的内部标签中；引导路线会同时定位顶层领域和内部实验。

### 3.3 引导式实验路线

- **基础标定与解调（约 25 分钟）**：建立标定基线，比较温漂、故障和接触反演，再进入解调与控制链；
- **抓取与触觉（约 35 分钟）**：完成二维寻找与抓取、三维抓稳条件核对、多材质触觉比较及融合汇总；
- **足底与装配（约 30 分钟）**：比较步态和低载荷边界，执行空载装配筛查并归档足底实验；
- **形状与结构健康（约 40 分钟）**：依次完成连续体重建、点式异常定位、分布式机制比较和综合报告；
- **光学机制与数据兼容（约 35 分钟）**：比较分布式、偏振与干涉观测量，载入八列示例并生成光学综合记录；
- **电子皮肤与多模态（约 45 分钟）**：依次完成三轴校正、光学感受野、稀疏压力重建和动态事件判别；
- 六条路线共同覆盖②至⑦的全部内部实验，每条路线显示前置建议、学习目标、覆盖模块和最终产物，并可下载带完成状态的文本记录；
- 每一步同时给出操作要求和预期现象；“我已完成并记录观察”由用户主动勾选，不是模型自动评分；
- 切换路线会保留各自进度；“重置本路线进度”只清空当前路线，不修改公共参数、实验输入、姿态或任务状态；
- 进度保存在当前 Streamlit 会话中，刷新或关闭会话后不保证继续保留。正式实验结果应使用页面提供的 JSON、CSV 或报告下载。

### 3.4 每页通用操作

- 滑杆/下拉改变输入，图表和指标立即更新；
- ② 页用“重置本页参数”恢复局部输入；⑧/⑨ 页提供“重置本页演示参数”。本页重置与侧栏公共参数恢复的作用范围不同；
- 图表下方一般有说明文字，讲怎么看这张图（峰值位置、颜色含义、单位等）；
- 需要数据的页面提供 CSV 下载按钮。

## 4. 逐页说明

### ② FBG 基础与解调 · 弯曲标定与诊断

- **示例实验**：选择后点击“载入示例”。三组示例均使用 45°、80 mm、1 mm 偏置、嵌入式和随机种子 17；“温漂对照”仅增加 20°C 温差，“噪声对照”仅增加 0.02 nm 噪声。
- **单指实验**：默认只展开真实角度；长度、光纤偏置和连接方式位于“进阶：几何与连接方式”。并列查看未温补角与 FBG 融合角，柱图对比原始读数与扣除已知温漂后的读数。偏置为零时显示“不可反演”，不是 0°。
- **基线 A 与当前 B**：保存 A 后再调节一个条件；A 不会随当前参数变化。表格列出改变的输入、两次反演角、误差及差值。“恢复基线 A 的参数”恢复单指输入及相关测量条件。
- **保存与恢复实验记录**：下载 JSON 保留当前 B 和可选 A；可在新会话上传并点击“导入参数并替换基线 A”。导入先校验格式、版本和参数，再重新计算结果，不采用文件中的旧结果。中文摘要包含实验输入和结果；CSV 仍可单独下载原始读数。
- **公共条件影响范围**：载入示例、恢复 A、导入记录会同步侧栏温度、噪声、漂移、失效通道和种子，因此会影响其他模块的测量条件；不会改动姿态、任务、采样率和复装工况。
- **重置本页参数**：只恢复本页弯曲、冗余故障和接触输入，保留公共条件及 A。侧栏“演示预设（恢复公共参数）”只恢复公共条件。刷新或关闭会话可能丢失 A，请先下载记录。
- **故障融合**：普通三路按已知温差补偿后平均应变，不自动剔除手动失效通道；被选中的手部通道用侧栏漂移值替代。下面的四路冗余模块单独演示异常通道剔除。
- **冗余与接触**：调节冗余故障类型观察容错反演；调节接触位置与力观察反演结果。这两项不包含在单指 JSON 记录中。

### ③ 手部抓取与触觉 · 二维抓取

- 左栏顶部：任务（开始/下一步）、六个预设动作（抬臂/伸手/抓取/按压/松开/复位）；
- 左栏中下：肩/肘/腕、五指屈曲、罐体与肩部位移滑杆；
- 右侧：二维 SVG 动画（自动播放过渡，接触手指变黄）+ 六路 FBG 读数；
- 抓稳判定：拇指 + 至少两根手指的接触力达到阈值，罐体才会绑定掌心。
- **重复采样与布置实验**：选择 20–200 次采样，侧栏波长噪声会逐次扰动六路读数；页面统计抓稳率、与无噪声基准的一致率、翻转次数及反演力均值/标准差，并比较六路、五路和三路布置的当前受力覆盖与判定可观测性。
- 可分别下载单次六路读数/报告，以及逐次采样 CSV/稳健性报告。

### ③ 手部抓取与触觉 · 三维抓取

- 左栏顶部：任务、张开/复位/握拳预设；
- 左栏中下：肩/肘/腕 + 14 个指节滑杆（两列）+ 罐体 X/Y/Z；
- 右侧：Three.js 三维手（可拖动旋转，滚轮缩放关闭），接触手指的青色光纤变黄；
- **查看抓稳条件与当前读数**：逐项显示掌心、拇指和其余手指条件，未抓稳时明确列出尚未满足的项；三个条件全部满足才通过，稳定度百分比不代替条件判定。
- **传感通道对照**：选择手指或掌心，在六路总览和十五路细分图中标出对应柱。橙色是选择标记，不是故障或受力阈值；力图与应变图分别使用 N 与 με。
- **噪声边界**：六路总览加入侧栏噪声；交互视图的当前抓稳状态仍使用未叠加噪声的模型信号。独立的重复采样实验会在 15 路触觉 FBG 上逐次加噪，统计抓稳率、一致率、翻转次数和反演力离散程度，用于比较教学模型的判定稳定性，不能证明真实硬件抗噪性能。
- 底部有“分布式光纤视角”：同一抓取状态下，五指沿光纤的连续应变曲线 + DAS 热图，与点式 FBG 对比。
- **布置可观测性**：六路、仅五指和稀疏三路布置按当前受力计算覆盖率；只有能观察掌心、拇指和全部其余手指候选通道的布置，才标为可完整执行三维规则。
- 可分别下载单次六路总览/报告，以及逐次采样 CSV/稳健性报告。

### ③ 手部抓取与触觉 · 材质识别

- **推荐场景**：标准海绵、硬块对照、圆柱接触、标准薄板和高扰动薄板；选择后必须点击“载入触觉场景”，它会同步本页输入及侧栏温度、波长噪声和随机种子；
- 六路波长先做已知温度补偿，再反演五指＋掌心接触力并参与分类，因此侧栏波长噪声会影响分类；
- **类别间隔**是最高类别与次高类别的概率差，**模板偏差**比较归一化接触形状，**重复一致率**使用相同条件和连续随机种子重复 24 次；
- 点击“保存当前为触觉基线 A”后，可继续改变材质或扰动并在表格中比较当前 B；基线不会随滑杆变化；
- 理想或反演总接触力低于 0.5 N 时页面会标记接触不足，不把零读数或噪声造成的微小正值当成材料结论；
- CSV 保存六路理想接触力、FBG 反演接触力和波长读数；文本报告保存当前条件、三项指标及模型边界。

### ④ 足底感知与装配 · 平衡与步态

- **推荐场景**：平地中期、脚跟着地、前掌蹬离、柔软地面对照、波长噪声对照和摆动期低载荷；选择后必须点击“载入足底场景”。载入会清除侧栏模拟失效与替代漂移，先建立可复现的标准场景；需要观察失效时再手动选择“足底区域 1”；
- 地形、总载荷、步态相位、支撑期/摆动期共同决定真实六区载荷；六路 FBG 经已知温度补偿后得到反演载荷；
- 页面并列显示真实/反演支撑力、六区平均绝对误差（区域 MAE）和归一化足底坐标中的 CoP 位置误差；
- 相位 0% 偏脚跟、100% 偏前掌；真实载荷低于 20 N 时，页面明确标记 CoP 仅供参考；
- 侧栏选择“足底区域 1”失效时，真实载荷仍保留，仅替换该传感通道读数，误差指标会反映这次失效；
- 点击“保存当前为足底基线 A”后，可比较地形、状态和误差的当前 B；CSV 与文本报告可用于复核页面结果。

### ⑤ 形状与结构监测 · 连续体形状

- **推荐场景**：理想恒曲率、扭转形状、波长噪声对照和芯间温差对照；选择后点击“载入形状场景”；
- 真实曲率/方向与反演结果、已知扭转先验同时显示，中心线 RMSE 衡量整条曲线误差，末端误差只衡量最后一个点；
- 可保存当前为形状基线 A，再改变噪声、已知扭转先验或芯间温差比较当前 B；
- 芯间温度梯度增大后，共模差分补偿失效，曲率、方向和空间中心线误差随之变化；
- CSV 保存真实与反演中心线及逐点空间误差，文本报告保存条件、四项误差和模型边界；
- “与分布式传感的联动”面板展示：沿长度均匀应变 → 恒定曲率 → 圆弧形状，与分布式 Rayleigh 局部峰对比。

### ⑤ 形状与结构监测 · 结构健康

- **推荐场景**：健康基线、局部异常、稀疏阵列、高密度阵列和噪声定位对照；选择后点击“载入健康场景”；
- 页面区分异常检测和异常定位：健康状态不计算定位误差，检测到设定异常后才比较真实位置与可疑位置；
- 可疑位置带 ± 定位区间（约为 FBG 间距一半），加密阵列可以缩小不确定度；可保存基线 A 比较阵列密度和噪声；
- CSV 保存每个传感器的位置、异常剖面、应变和波长；报告明确“需检查”不等同于安全结论；
- “分布式 vs 点式 FBG”对比：连续曲线能读出峰的位置与宽度，点式只能给区间。

### ⑥ 分布式光学与数据 · 分布式感知

- **推荐场景**：Rayleigh 局部应变、DAS 振动事件、Brillouin 应变温度、Raman 局部温升和稀疏采样对照；载入场景会同步侧栏采样率；
- 页面给出采样后估计事件位置和定位误差，可保存基线 A 比较机制或采样间隔；CSV 保存当前空间剖面，文本报告保存输入、定位误差和模型边界；
- 四种机制（Rayleigh/OFDR、DAS、Brillouin、Raman）看同一个事件；
- “空间采样间隔”调大可看到峰被低估或漏掉——空间分辨率的直观演示；
- “四机制对比视图”并排展示四种曲线/热图；
- “Brillouin × Raman 温补解耦”：温度会伪装成应变（1 °C ≈ 22 με），用 Raman 测温度后从频移扣除，还原真实应变。

### ⑥ 分布式光学与数据 · 偏振与干涉

- **推荐场景**：偏振基线、横向应力、光纤扭转、温度交叉敏感和旋转与压力；选择后点击“载入光学场景”；
- 庞加莱球上的向量端点表示偏振态，页面同时给出 Stokes S1/S2/S3、方位角、椭圆率和温度引起的椭圆率偏移；
- EFPI 谱条纹随腔长变化，页面显示压力引起的有效腔长变化；Sagnac 区域显示输入角速度对应的相位差；
- “机制响应曲线与可辨识性”分开显示 Sagnac 的角速度—相位关系和 EFPI 的压力—腔长关系，避免把三种机制误认为同一测量链；
- 可保存当前为光学基线 A，再改变应力、扭转、温度、角速度或压力，使用同一张表比较当前 B；
- “双折射—扭转—温度联合视图”用网格图展示应力/扭转对偏振态的影响。

### ② FBG 基础与解调 · 解调与实验任务

- **推荐链路实验**：快速响应基线、阈值附近噪声、强滤波对照和温漂补偿；载入场景会同步弯曲角、噪声、窗口、阈值、温度与采样率；
- 三条曲线依次为原始、滤波、温补后的波长流；可调移动平均窗口和闭合控制阈值；
- 页面量化原始/滤波后噪声 RMS、理论滤波延迟、阈值裕量和逐采样指令一致率，用于比较降噪与响应速度；
- 可保存链路基线 A，再改变滤波窗口或阈值形成当前 B 对照；理论延迟不包含真实解调器、通信与执行器延迟；
- 下方多模态融合会综合抓取、足底、形状、健康、分布式质量，给出“任务就绪 / 需人工复核”；
- 八类实验任务分别显示三步操作提示，下载报告包含所选模块的完整当前记录与共享感知链摘要；冗余故障报告会区分注入通道与诊断通道。

### ④ 足底感知与装配 · 装配校验

- 页面顶部给出学习目标、建议操作、重点观察和模型边界；建议依次比较正常装配、压入不足与单侧错位；
- 传力场热图：亮区为传力集中处，错位时亮区中心横向偏移；
- 容差混淆矩阵：对角线越高越好，非对角格表示误判；
- 密封压缩率、预应变保持率是试验规划假设，不是寿命预测。

### ⑥ 分布式光学与数据 · 数据兼容

- 内置练习包括标准空白八列、带表头 CSV、列数不足和位置重复；后两项用于观察明确的拒绝原因；
- 合法数据会显示位置跨度、采样间隔范围/变异和八列最小—最大值，再提供标准化下载；
- 上传八列文本（最大 8 MB、最多 100,000 个有效采样行；可自动识别分隔符/跳过行数），检查通过后可下载标准化文本；
- 该页只做结构检查，不包含、不修改 FBG-SimPlus 源码。


### ⑦ 电子皮肤与多模态感知

- **系统总览与机制对照**：比较压阻、电容、压电/摩擦电、离子和 FBG 光学方案的观测量、适用任务与常见干扰；
- **三轴触觉单元**：调节 Fx/Fy/Fz、曲率、应变、温度、噪声和参考匹配度；页面显示五通道主动/参考/校正信号、三轴反演误差、矩阵秩和条件数；
- **FBG 光学皮肤**：选择 4/8/16 个传感点、单点/双点接触、感受野和温度；双点只评价合力和载荷质心，不声称唯一分离两个接触点；
- **稀疏压力重建**：从 4×4 或 8×8 采样重建 16×16 或 32×32 压力场，并同时检查 RMSE、峰值、质心、总载荷与通道节省率；
- **动态滑移与多模态**：比较六类时间序列，滑移告警要求剪切比和压力质心速度同时越阈，并提供 20–200 次重复告警统计；
- 四个实验都可保存基线 A、下载 CSV 和 Markdown 报告。全部结果为可复现教学仿真，不能替代器件标定、实物测试或安全认证。

## 7. 模型边界（重要）

- 全部为解析教学模型，不是 COMSOL 或真实硬件的替代品；
- 接触力、足底载荷、分布式信号等是简化模型，真实系统需要封装、温度场、动态载荷和标定数据；

## 8. 常见问题

**Q：启动后页面空白/报错？**
先确认依赖装全：`python -m pip install -r requirements.txt`，再 `python -m streamlit run app.py`。

**Q：跨页“下一步”按钮点了没反应？**
这些按钮使用 Streamlit 原生导航状态切换标签。若点击后仍未跳转，请刷新页面后重试，或直接点击顶部目标标签。

**Q：手部动作总是重播动画，拖动时卡卡的？**
在侧边栏关闭“平滑过渡动画（2D/3D 手）”，动作会直接跳变到当前姿态，不再重播过渡。

**Q：想换默认参数？**
侧边栏改好参数后，点“演示预设”之前的数值会保留在会话里；刷新页面会回到默认。

**Q：跑测试？**
```bash
python -m pytest tests -p no:cacheprovider
```

请在项目根目录、已激活 Python 环境且已安装 `requirements.txt` 后执行。该测试不依赖浏览器或网络，但要求 `fiber_robotics_sim/vendor/three.min.js` 等仓库文件完整可用。

## 9. 代码结构（想改代码时看这里）

```
app.py                      # Streamlit 界面：侧边栏、7 个领域标签、内部实验与状态
fiber_robotics_sim/
  models.py                 # 正演/反演模型、碰撞、分布式与融合（与界面无关）
  experiments.py            # 实验预设、量化结果、CSV 与文本报告
  visuals.py                # Plotly 图表、SVG/Three.js 渲染、图表函数
  vendor/three.min.js       # 本地 Three.js 运行时
tests/                      # 模型、实验内容、引导流程和页面级测试
docs/                       # 文档（迁移与 FBG-SimPlus、本指南）
```

改代码的约定：模型逻辑放 `models.py`，实验记录与报告放 `experiments.py`，图表/渲染放 `visuals.py`，页面放 `app.py`；日常修改可只跑相关测试，发布前再运行完整测试。
