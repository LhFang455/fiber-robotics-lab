# 光纤机器人传感仿真实验室 · 用户指南（新手版）

本指南面向第一次接触这个网站的新手，按“启动 → 界面 → 逐页说明 → 演示功能 → 常见问题”的顺序介绍。读完大约 10 分钟，之后你就能自己玩起来。

## 1. 这是什么

这是一个本地运行的 Streamlit 教学演示网站，用来展示**光纤传感 + 机器人感知**的完整链路：

光纤传感（抓取、触觉、足底、形状、健康）→ 光纤解调（波长读取、温补、故障隔离）→ 状态估计（CoP、曲率、异常位置）→ 控制与任务（命令输出、报告）。

所有模型都是可解释的解析教学模型，页面会同时给出“真实量”和“反演量”，方便对比。它不是商业产品，也不替代真实硬件标定。

## 2. 快速开始

### 2.1 环境要求

- Python 3.10+；本机已验证 macOS 26.6.2（Apple Silicon）与 Python 3.13.9。Windows 与 Linux 具备运行条件，但尚未在真实机器完成验收。
- 依赖：`numpy`、`plotly`、`streamlit`、`pytest`（测试用）
- 虚拟环境：可使用任意 Python 虚拟环境工具；差异仅在创建和激活方式，激活后的安装、启动和测试命令相同。

### 2.2 安装与启动

以下以 Python 内置 `venv` 为例，给出从下载到启动的完整命令。若使用其他虚拟环境工具，只需按该工具的方式创建并激活环境，再执行对应代码块中的安装与启动命令。

macOS/Linux：

```bash

cd fiber-robotics-lab
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows PowerShell：

```powershell

cd fiber-robotics-lab

.\.venv\Scripts\Activate.ps1
```

## 3. 界面总览

### 3.1 侧边栏（左侧固定栏）

- **← 返回主页**：无论你在哪个页面，点它回到 ① 系统总览；
- **公共光学与测量参数**：温度变化、波长噪声、零点漂移、采样率、模拟失效通道、复装工况、随机种子，所有页面共用；
- **演示预设（恢复推荐参数）**：一键把公共参数恢复为推荐值，演示前点一下；
- **平滑过渡动画（2D/3D 手）**：默认开启，手部动作会平滑过渡；关闭后直接跳变，适合快速调试参数。

> 提示：随机种子让同一参数下的结果可复现，适合做演示和对比实验。

### 3.2 标签页顺序（推荐按这个顺序体验）

1. **① 系统总览**：模块目录（可点击跳转）、系统架构示意、当前配置、感知链说明、推荐路径；

3. **③ 二维手部抓取**：平面手的指令按钮 + 动画视图，左上为指令（任务/预设），左中为滑杆，右侧为动画和 FBG 读数；
4. **④ 三维抓取传感**：14 个独立指节的三维手，带碰撞限位和分布式光纤视角；
5. **⑤ 多材质触觉识别**：海绵/硬块/圆柱/薄板的接触模式分类；
6. **⑥ 足底平衡与步态**：六区载荷、二维 CoP、步态相位；
7. **⑦ 连续体形状重建**：三芯光纤曲率/方向/扭转反演；
8. **⑧ 机械臂健康监测**：FBG 阵列定位异常，带定位不确定区间；
9. **⑨ 分布式光纤感知**：Rayleigh、DAS、Brillouin、Raman 四机制对比，含温补解耦；
10. **⑩ 偏振与干涉传感**：Stokes 偏振态、Sagnac 陀螺、EFPI 干涉谱；
11. **⑪ 解调器与实验任务**：实时波长流、温补、控制输出、多模态融合报告；
12. **⑫ 可更换足底装配校验**：空载装配筛查、容差/密封/预应变敏感性；

## 4. 逐页说明

### ② FBG 标定与诊断

- **单指弯曲**：调节真实弯曲角，观察三枚 FBG 的波长漂移柱状图——温度只抬高整体基线，弯曲角由通道间差异反演；
- **冗余故障**：选择故障类型/通道，四路柱高会有一路明显偏离中位数，诊断会剔除该通道后反演角度；
- **接触反演**：接触点附近的 FBG 应变最高，反演接触位置与法向力由网格最小二乘恢复。

### ③ 二维手部抓取

- 左栏顶部：任务（开始/下一步）、六个预设动作（抬臂/伸手/抓取/按压/松开/复位）；
- 左栏中下：肩/肘/腕、五指屈曲、罐体与肩部位移滑杆；
- 右侧：二维 SVG 动画（自动播放过渡，接触手指变黄）+ 六路 FBG 读数；
- 抓稳判定：拇指 + 至少两根手指的接触力达到阈值，罐体才会绑定掌心。

### ④ 三维抓取传感

- 左栏顶部：任务、张开/复位/握拳预设；
- 左栏中下：肩/肘/腕 + 14 个指节滑杆（两列）+ 罐体 X/Y/Z；
- 右侧：Three.js 三维手（可拖动旋转，滚轮缩放关闭），接触手指的青色光纤变黄；
- 底部有“分布式光纤视角”：同一抓取状态下，五指沿光纤的连续应变曲线 + DAS 热图，与点式 FBG 对比。

### ⑤ 多材质触觉识别

- 选目标材质、握持力、接触面积、接触模式扰动；
- 六路柱状图是五指＋掌心的触觉模式；“识别概率”柱越高越像该材质；
- 扰动/噪声会让概率摊平甚至误判——这就是真实识别的不确定性。

### ⑥ 足底平衡与步态

- 地形、总载荷、步态相位、支撑期/摆动期共同决定六区载荷；
- 相位 0% 偏脚跟、100% 偏前掌，CoP 以二维坐标显示在脚底图上；
- 手动拖动“步态相位”即可观察载荷与 CoP 随前掌/脚跟转移。

### ⑦ 连续体形状重建

- 真实曲率/方向/扭转 vs 反演结果，看三维中心线的实线/虚线是否重合；
- 芯间温度梯度滑杆调大后，差分补偿失效，反演误差增大；
- “与分布式传感的联动”面板展示：沿长度均匀应变 → 恒定曲率 → 圆弧形状，与分布式 Rayleigh 局部峰对比。

### ⑧ 机械臂健康监测

- 调节载荷、异常位置、异常程度、FBG 阵列密度；
- 可疑位置带 ± 定位区间（约为 FBG 间距一半），加密阵列可以缩小不确定度；
- “分布式 vs 点式 FBG”对比：连续曲线能读出峰的位置与宽度，点式只能给区间。

### ⑨ 分布式光纤感知

- 四种机制（Rayleigh/OFDR、DAS、Brillouin、Raman）看同一个事件；
- “空间采样间隔”调大可看到峰被低估或漏掉——空间分辨率的直观演示；
- “四机制对比视图”并排展示四种曲线/热图；
- “Brillouin × Raman 温补解耦”：温度会伪装成应变（1 °C ≈ 22 με），用 Raman 测温度后从频移扣除，还原真实应变。

### ⑩ 偏振与干涉传感

- 庞加莱球上的向量端点表示偏振态（方位角/椭圆率）；
- EFPI 谱条纹周期随腔长变化，压力改变条纹疏密；
- “双折射—扭转—温度联合视图”用网格图展示应力/扭转对偏振态的影响。

### ⑪ 解调器与实验任务

- 三条曲线依次为原始、滤波、温补后的波长流；
- 滤波平滑噪声、温补扣除共模温度、控制输出按反演角阈值触发；
- 下方多模态融合会综合抓取、足底、形状、健康、分布式质量，给出“任务就绪 / 需人工复核”。

### ⑫ 可更换足底装配校验

- 传力场热图：亮区为传力集中处，错位时亮区中心横向偏移；
- 容差混淆矩阵：对角线越高越好，非对角格表示误判；
- 密封压缩率、预应变保持率是试验规划假设，不是寿命预测。

### ⑬ FBG-SimPlus 兼容

- 上传八列文本（自动识别分隔符/跳过行数），检查通过后可下载标准化文本；
- 该页只做结构检查，不包含、不修改 FBG-SimPlus 源码。

## 7. 模型边界（重要）

- 全部为解析教学模型，不是 COMSOL 或真实硬件的替代品；
- 接触力、足底载荷、分布式信号等是简化模型，真实系统需要封装、温度场、动态载荷和标定数据；
- “接触位置/力”尤其简化，仅用于理解传感器布置与可辨识性；
- 页面中的“需检查”“抓稳”等是教学阈值，不等同于安全或质量结论。

## 8. 常见问题

**Q：启动后页面空白/报错？**
先确认依赖装全：`python -m pip install -r requirements.txt`，再 `python -m streamlit run app.py`。

**Q：跨页“下一步”按钮点了没反应？**
这些按钮通过页面内脚本点击标签，需要保持浏览器默认设置（允许脚本）；如果仍不工作，请手动点顶部标签。

**Q：手部动作总是重播动画，拖动时卡卡的？**
在侧边栏关闭“平滑过渡动画（2D/3D 手）”，动作会直接跳变到当前姿态，不再重播过渡。

**Q：想换默认参数？**
侧边栏改好参数后，点“演示预设”之前的数值会保留在会话里；刷新页面会回到默认。

**Q：跑测试？**
```bash
python -m pytest tests/test_models.py -p no:cacheprovider
```

请在项目根目录、已激活 Python 环境且已安装 `requirements.txt` 后执行。该测试不依赖浏览器或网络，但要求 `fiber_robotics_sim/vendor/three.min.js` 等仓库文件完整可用。

## 9. 代码结构（想改代码时看这里）

```
app.py                      # Streamlit 界面：侧边栏、13 个标签页、状态与演示功能
fiber_robotics_sim/
  models.py                 # 正演/反演模型、碰撞、标定、分布式、融合（与界面无关）
  visuals.py                # Plotly 图表、SVG/Three.js 渲染、图表函数
  vendor/three.min.js       # 本地 Three.js 运行时
tests/test_models.py        # 模型、图表、页面级测试
docs/                       # 文档（迁移与 FBG-SimPlus、本指南）
```

改代码的约定：模型逻辑放 `models.py`，图表/渲染放 `visuals.py`，页面放 `app.py`；改完只跑相关测试即可。
