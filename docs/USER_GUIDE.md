# 光纤机器人传感仿真实验室 · 用户指南

本指南按“启动 → 界面 → 逐页说明 → 演示功能 → 常见问题”的顺序，介绍网站的主要功能与操作方式。

## 1. 这是什么

这是一个本地运行的 Streamlit 教学演示网站，用来展示**光纤传感 + 机器人感知**的完整链路：

光纤传感（抓取、触觉、足底、形状、健康）→ 光纤解调（波长读取、温补、故障隔离）→ 状态估计（CoP、曲率、异常位置）→ 控制与任务（命令输出、报告）。

所有模型都是可解释的解析教学模型，页面会同时给出“真实量”和“反演量”，方便对比。它不是商业产品，也不替代真实硬件标定。

## 第一次使用的操作路径

1. 首页点击“开始第一个实验：弯曲标定”。这只打开页面，不会重置已有输入；也可从目录或侧栏搜索直达其他实验。
2. 按模型前方始终可见的“动手操作 → 看懂结果 → 留下记录”引导完成一次实验。真实量是仿真设置的输入，反演量是从传感读数估算的结果；两者差异用于观察误差。
3. 参数修改后自动计算，无需提交。公共测量条件在侧栏直接显示；首次先保持默认值，之后只改一个条件。手机上点左上角箭头打开侧栏。
4. 点击页首“跳到记录与导出”保存结果。提供基线的页面可先保存 A，再调整条件比较当前 B；记录区也有返回页首的链接。
5. 继续学习时，首页六条路线直接显示步骤、预期观察和进入按钮。步骤勾选仅记录学习进度，不代表验证通过。

常用参数、实验说明、抓稳条件、记录恢复及模型显示开关直接可见；安装说明、重复采样明细等进阶内容保留折叠。模型内的播放仅演示过程，不替用户改变页面实验参数。现有计算、基线、导出和导航状态保持原有逻辑。

## 2. 快速开始

### 2.1 环境要求

- Python 3.10+；本机已验证 macOS 26.6.2（Apple Silicon）与 Python 3.13.9。Windows 与 Linux 具备运行条件，但尚未在真实机器完成验收。
- 依赖：`numpy`、`plotly`、`streamlit`、`pytest`（测试用）
- 虚拟环境：可使用任意 Python 虚拟环境工具；差异仅在创建和激活方式，激活后的安装、启动和测试命令相同。

### 2.2 安装与启动

以下以 Python 内置 `venv` 为例，给出从下载到启动的完整命令。若使用其他虚拟环境工具，只需按该工具的方式创建并激活环境，再执行对应代码块中的安装与启动命令。

macOS/Linux：

```bash
git clone https://github.com/LhFang455/fiber-robotics-lab.git
cd fiber-robotics-lab
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows PowerShell：

```powershell
git clone https://github.com/LhFang455/fiber-robotics-lab.git
cd fiber-robotics-lab
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。如果没自动打开，手动访问这个地址即可。

环境激活后，安装与启动命令在各平台一致。

### 2.3 先跑一遍推荐路径

1. 首次参观或汇报时，先在 **① 系统总览** 打开“3 分钟看懂光纤感知”，依次播放三章成果演示；它使用独立固定预设，不会修改侧栏、实验基线或学习进度；
2. 需要系统学习时，点侧边栏“演示预设（恢复公共参数）”，恢复公共测量条件；各页局部参数需用对应的重置按钮恢复；
3. 回到 **① 系统总览**，在“引导式实验路线”选择六条路线之一；六条路线共同覆盖②至⑦的全部内部实验；
4. 阅读每一步的操作和预期观察，点击“进入第 N 步”跳转；完成观察后再主动勾选；
5. 按所选路线完成页面产物，并下载“当前路线学习记录”。路线勾选仅记录学习进度，不判断实验是否正确。

页面底部有“下一步 →”按钮，可以按推荐路径直接跳转。

## 3. 界面总览

### 3.1 侧边栏（左侧固定栏）

- **← 返回主页**：无论你在哪个页面，点它回到 ① 系统总览；
- **快速模块导航**：下拉选择任一领域实验室即可直接跳转；进入领域后再用内部标签选择实验；
- **公共光学与测量参数**：温度变化、波长噪声、零点漂移、采样率、模拟失效通道、复装工况、随机种子，所有页面共用；
- **演示预设（恢复公共参数）**：只把上方公共参数恢复为推荐值，不重置各页局部参数、手部姿态或任务进度；
- **平滑过渡动画（2D/3D 手）**：默认开启，手部动作会平滑过渡；关闭后直接跳变，适合快速调试参数。

> 提示：随机种子让同一参数下的结果可复现，适合做演示和对比实验。

### 3.2 两层导航顺序（推荐按这个顺序体验）

1. **① 系统总览**：六条引导式实验路线、领域目录、系统架构示意、当前配置和感知链说明；
2. **② FBG 基础与解调**：弯曲标定与诊断；解调与实验任务；
3. **③ 手部抓取与触觉**：二维抓取；三维抓取；材质识别；
4. **④ 足底感知与装配**：平衡与步态；装配校验；
5. **⑤ 形状与结构监测**：连续体形状；结构健康；
6. **⑥ 分布式光学与数据**：分布式感知；偏振与干涉；FBG-SimPlus 数据兼容；
7. **⑦ 电子皮肤与多模态感知**：三轴触觉单元；FBG 光学皮肤；稀疏压力重建；动态滑移与多模态。

顶层标签只代表领域。原有实验没有删除，均放入对应领域的内部标签中；引导路线会同时定位顶层领域和内部实验。

### 3.3 引导式实验路线

首页顶部的“3 分钟看懂光纤感知”面向参观者和汇报场景：三章分别演示足底 CoP 迁移、FBG 温度交叉敏感与温补、4×4/8×8 稀疏压力重建对照。它默认收起，同时只生成当前章节的一个播放器；可手动前后切换，并从章末进入对应完整实验。压力对照使用相同真实压力场、输出网格、带宽、噪声和随机种子，只改变采样网格，结论以实时计算的四项指标为准。

- **基础标定与解调（约 25 分钟）**：建立标定基线，比较温漂、故障和接触反演，再进入解调与控制链；
- **抓取与触觉（约 35 分钟）**：完成二维寻找与抓取、三维抓稳条件核对、多材质触觉比较及融合汇总；
- **足底与装配（约 30 分钟）**：比较步态和低载荷边界，执行空载装配筛查并归档足底实验；
- **形状与结构健康（约 40 分钟）**：依次完成连续体重建、点式异常定位、分布式机制比较和综合报告；
- **光学机制与数据兼容（约 35 分钟）**：比较分布式、偏振与干涉观测量，载入八列示例并生成光学综合记录；
- **电子皮肤与多模态（约 45 分钟）**：依次完成三轴校正、光学感受野、稀疏压力重建和动态事件判别；
- 六条路线共同覆盖②至⑦的全部内部实验，每条路线显示前置建议、学习目标、覆盖模块和最终产物，并可下载带完成状态的文本记录；
- 每一步同时给出操作要求和预期现象；“我已完成并记录观察”由用户主动勾选，不是模型自动评分；
- 切换路线会保留各自进度；“重置本路线进度”只清空当前路线，不修改公共参数、实验输入、姿态或任务状态；
- 进度保存在当前 Streamlit 会话中，刷新或关闭会话后不保证继续保留。正式实验结果应使用页面提供的 JSON、CSV 或报告下载。

### 3.4 每页通用操作

- 滑杆/下拉改变输入，图表和指标立即更新；
- ② 页用“重置本页参数”恢复局部输入；⑧/⑨ 页提供“重置本页演示参数”。本页重置与侧栏公共参数恢复的作用范围不同；
- 图表下方一般有说明文字，讲怎么看这张图（峰值位置、颜色含义、单位等）；
- 需要数据的页面提供 CSV 下载按钮。

### 3.5 面向参观者的直观模型演示

以下十二个实验开头提供“显示直观模型演示”开关：

| 入口 | 可直观看到的过程 | 讲解重点 |
|---|---|---|
| ④ 足底感知与装配 → 平衡与步态 | 六区载荷随相位由脚跟向前掌迁移，真实与反演压力中心同步显示 | 白点是真实 CoP，橙环是反演 CoP；低载荷或失效时只作参考 |
| ⑤ 形状与结构监测 → 连续体形状 | 实体连续体逐渐弯曲，与三芯波长反演轨迹对照 | 青色实体与橙色反演线；芯间温差会造成误差；扭转率为已知先验 |
| ⑦ 电子皮肤与多模态感知 → FBG 光学皮肤 | 一个或两个压头按下、平移、释放，光点与温补波长联动 | 多个触点只评价合力质心；表面凹陷不是实际位移或压力重建 |
| ② FBG 基础与解调 → 弯曲标定与诊断 | 先改变机械应变，再施加温差；光栅纹理与原始/温补波长联动 | 推荐载入“温漂对照”；形变放大倍数显示在面板下方，中性层不可反演 |
| ④ 足底感知与装配 → 装配校验 | 分层观察七类部件，再复位并读取两枚工作光栅和参考光栅 | 进度起点为分离状态，无读数；75% 后显示当前工况的空载筛查，未模拟装配过程受力 |
| ⑤ 形状与结构监测 → 结构健康 | 局部异常程度增加，阵列响应与有效定位区间同步变化 | 红环为仿真真值，橙色区间为教学定位范围；未形成有效定位时不显示估计标记 |
| ③ 手部抓取与触觉 → 材质识别 | 海绵、硬块、圆柱、薄板在相同输入下加载和卸载，六路反演接触力并列显示 | 金色台面为当前材质，柱高使用同一比例；这是预设接触模板，不计算刚度或压痕 |
| ⑥ 分布式光学与数据 → 分布式感知 | 沿光纤依次读取空间剖面，显示当前采样值与有效事件位置 | 游标不是光脉冲或事件传播；Brillouin 双源叠加和平坦剖面不报告单事件定位 |
| ⑥ 分布式光学与数据 → 偏振与干涉 | 选择偏振球与电场椭圆、双向 Sagnac 环路或 EFPI 微腔与光谱 | 三种独立机制，不能串成同一传感链；微腔相对形变放大 20 倍，真实读数保持原单位 |
| ⑦ 电子皮肤与多模态感知 → 动态滑移与多模态 | 同步回放质心位置、法向与剪切力、温度及窗口峰值判据 | 六类事件沿用原时序；质心不是物体轨迹，告警不要求同一采样时刻越阈 |
| ⑦ 电子皮肤与多模态感知 → 三轴触觉单元 | 真实、未校正与参考校正三组力向量并列，先加载再施加共模干扰 | 负分量反向，箭头共用比例；校正是否改善以原模型 MAE 为准，不夸大参考校正收益 |
| ⑦ 电子皮肤与多模态感知 → 稀疏压力重建 | 真实压力面、稀疏测量点、核插值重建面并列，最后标出最大绝对误差点 | 先读取、再显示完整计算结果；曲面高度不是位移，显示进度不是算法迭代 |

- **播放 / 暂停、重播、进度条与速度**仅改变演示面板内的进度，不改写下方实验参数；单次播放结束后停止。
- **当前参数**回到与下方图表可对照的一帧。足底定位到当前相位，连续体定位到目标曲率，皮肤定位到原接触位置和载荷的按压帧；装配、结构健康和 FBG 对应当前工况、异常程度或弯曲/温度输入；材质对照定位到当前握持力的加载峰值，分布式定位到空间读取结束，光学定位到当前机制输入；动态滑移定位到记录末帧，窗口结果与下方整段记录指标一致；三轴回到当前力与全部干扰条件，压力重建显示完整采样和重建结果。
- **拖动模型**可旋转观察，**复位视角**恢复全景；滚轮不缩放模型。**全屏**同时保留模型、读数和讲解，适合汇报。
- 默认暂停，离开演示或隐藏页面会暂停；减少动态效果偏好下可用进度条逐帧查看。
- 除动态滑移外，演示为参数扫描、空间读取或结果显示，播放时长不是物理时间。动态滑移面板则回放原采样记录，1× 按记录时间推进，0.5×/1.5× 改变播放速度；完整保留采样点，但屏幕刷新可能跳过中间帧，可暂停后用进度条和方向键逐点检查。它不是实时测量或完整接触动力学；定量分析和导出仍使用下方实验区。
- 分布式沿用原模型：Brillouin 应变源固定在 0.35L、温度源固定在 0.68L，位置滑块不参与；DAS 固定 60 Hz 振动，幅值滑块不参与。面板、指标与报告明确说明这些边界；Raman 不高于 20°C 背景、Rayleigh 零幅值等平坦剖面不报告定位。

## 4. 逐页说明

### ② FBG 基础与解调 · 弯曲标定与诊断

- **示例实验**：选择后点击“载入示例”。三组示例均使用 45°、80 mm、1 mm 偏置、嵌入式和随机种子 17；“温漂对照”仅增加 20°C 温差，“噪声对照”仅增加 0.02 nm 噪声。
- **单指实验**：默认只展开真实角度；长度、光纤偏置和连接方式位于“进阶：几何与连接方式”。并列查看未温补角与 FBG 融合角，柱图对比原始读数与扣除已知温漂后的读数。偏置为零时显示“不可反演”，不是 0°。
- **基线 A 与当前 B**：保存 A 后再调节一个条件；A 不会随当前参数变化。表格列出改变的输入、两次反演角、误差及差值。“恢复基线 A 的参数”恢复单指输入及相关测量条件。
- **保存与恢复实验记录**：下载 JSON 保留当前 B 和可选 A；可在新会话上传并点击“导入参数并替换基线 A”。导入先校验格式、版本和参数，再重新计算结果，不采用文件中的旧结果。中文摘要包含实验输入和结果；CSV 仍可单独下载原始读数。
- **公共条件影响范围**：载入示例、恢复 A、导入记录会同步侧栏温度、噪声、漂移、失效通道和种子，因此会影响其他模块的测量条件；不会改动姿态、任务、采样率和复装工况。
- **重置本页参数**：只恢复本页弯曲、冗余故障和接触输入，保留公共条件及 A。侧栏“演示预设（恢复公共参数）”只恢复公共条件。刷新或关闭会话可能丢失 A，请先下载记录。
- **故障融合**：普通三路按已知温差补偿后平均应变，不自动剔除手动失效通道；被选中的手部通道用侧栏漂移值替代。下面的四路冗余模块单独演示异常通道剔除。
- **冗余与接触**：调节冗余故障类型观察容错反演；调节接触位置与力观察反演结果。这两项不包含在单指 JSON 记录中。

### ③ 手部抓取与触觉 · 二维抓取

- 左栏顶部：任务（开始/下一步）、六个预设动作（抬臂/伸手/抓取/按压/松开/复位）；
- 左栏中下：肩/肘/腕、五指屈曲、罐体与肩部位移滑杆；
- 右侧：二维 SVG 动画（自动播放过渡，接触手指变黄）+ 六路 FBG 读数；
- 抓稳判定：拇指 + 至少两根手指的接触力达到阈值，罐体才会绑定掌心。
- **重复采样与布置实验**：选择 20–200 次采样，侧栏波长噪声会逐次扰动六路读数；页面统计抓稳率、与无噪声基准的一致率、翻转次数及反演力均值/标准差，并比较六路、五路和三路布置的当前受力覆盖与判定可观测性。
- 可分别下载单次六路读数/报告，以及逐次采样 CSV/稳健性报告。

### ③ 手部抓取与触觉 · 三维抓取

- 左栏顶部：任务、张开/复位/握拳预设；
- 左栏中下：肩/肘/腕 + 14 个指节滑杆（两列）+ 罐体 X/Y/Z；
- 右侧：Three.js 三维手（可拖动旋转，滚轮缩放关闭），接触手指的青色光纤变黄；
- **查看抓稳条件与当前读数**：逐项显示掌心、拇指和其余手指条件，未抓稳时明确列出尚未满足的项；三个条件全部满足才通过，稳定度百分比不代替条件判定。
- **传感通道对照**：选择手指或掌心，在六路总览和十五路细分图中标出对应柱。橙色是选择标记，不是故障或受力阈值；力图与应变图分别使用 N 与 με。
- **噪声边界**：六路总览加入侧栏噪声；交互视图的当前抓稳状态仍使用未叠加噪声的模型信号。独立的重复采样实验会在 15 路触觉 FBG 上逐次加噪，统计抓稳率、一致率、翻转次数和反演力离散程度，用于比较教学模型的判定稳定性，不能证明真实硬件抗噪性能。
- 底部有“分布式光纤视角”：同一抓取状态下，五指沿光纤的连续应变曲线 + DAS 热图，与点式 FBG 对比。
- **布置可观测性**：六路、仅五指和稀疏三路布置按当前受力计算覆盖率；只有能观察掌心、拇指和全部其余手指候选通道的布置，才标为可完整执行三维规则。
- 可分别下载单次六路总览/报告，以及逐次采样 CSV/稳健性报告。

### ③ 手部抓取与触觉 · 材质识别

- **推荐场景**：标准海绵、硬块对照、圆柱接触、标准薄板和高扰动薄板；选择后必须点击“载入触觉场景”，它会同步本页输入及侧栏温度、波长噪声和随机种子；
- 六路波长先做已知温度补偿，再反演五指＋掌心接触力并参与分类，因此侧栏波长噪声会影响分类；
- **类别间隔**是最高类别与次高类别的概率差，**模板偏差**比较归一化接触形状，**重复一致率**使用相同条件和连续随机种子重复 24 次；
- 点击“保存当前为触觉基线 A”后，可继续改变材质或扰动并在表格中比较当前 B；基线不会随滑杆变化；
- 理想或反演总接触力低于 0.5 N 时页面会标记接触不足，不把零读数或噪声造成的微小正值当成材料结论；
- CSV 保存六路理想接触力、FBG 反演接触力和波长读数；文本报告保存当前条件、三项指标及模型边界。

### ④ 足底感知与装配 · 平衡与步态

- **推荐场景**：平地中期、脚跟着地、前掌蹬离、柔软地面对照、波长噪声对照和摆动期低载荷；选择后必须点击“载入足底场景”。载入会清除侧栏模拟失效与替代漂移，先建立可复现的标准场景；需要观察失效时再手动选择“足底区域 1”；
- 地形、总载荷、步态相位、支撑期/摆动期共同决定真实六区载荷；六路 FBG 经已知温度补偿后得到反演载荷；
- 页面并列显示真实/反演支撑力、六区平均绝对误差（区域 MAE）和归一化足底坐标中的 CoP 位置误差；
- 相位 0% 偏脚跟、100% 偏前掌；真实载荷低于 20 N 时，页面明确标记 CoP 仅供参考；
- 侧栏选择“足底区域 1”失效时，真实载荷仍保留，仅替换该传感通道读数，误差指标会反映这次失效；
- 点击“保存当前为足底基线 A”后，可比较地形、状态和误差的当前 B；CSV 与文本报告可用于复核页面结果。

### ⑤ 形状与结构监测 · 连续体形状

- **推荐场景**：理想恒曲率、扭转形状、波长噪声对照和芯间温差对照；选择后点击“载入形状场景”；
- 真实曲率/方向与反演结果、已知扭转先验同时显示，中心线 RMSE 衡量整条曲线误差，末端误差只衡量最后一个点；
- 可保存当前为形状基线 A，再改变噪声、已知扭转先验或芯间温差比较当前 B；
- 芯间温度梯度增大后，共模差分补偿失效，曲率、方向和空间中心线误差随之变化；
- CSV 保存真实与反演中心线及逐点空间误差，文本报告保存条件、四项误差和模型边界；
- “与分布式传感的联动”面板展示：沿长度均匀应变 → 恒定曲率 → 圆弧形状，与分布式 Rayleigh 局部峰对比。

### ⑤ 形状与结构监测 · 结构健康

- **推荐场景**：健康基线、局部异常、稀疏阵列、高密度阵列和噪声定位对照；选择后点击“载入健康场景”；
- 页面区分异常检测和异常定位：健康状态不计算定位误差，检测到设定异常后才比较真实位置与可疑位置；
- 可疑位置带 ± 定位区间（约为 FBG 间距一半），加密阵列可以缩小不确定度；可保存基线 A 比较阵列密度和噪声；
- CSV 保存每个传感器的位置、异常剖面、应变和波长；报告明确“需检查”不等同于安全结论；
- “分布式 vs 点式 FBG”对比：连续曲线能读出峰的位置与宽度，点式只能给区间。

### ⑥ 分布式光学与数据 · 分布式感知

- **推荐场景**：Rayleigh 局部应变、DAS 振动事件、Brillouin 应变温度、Raman 局部温升和稀疏采样对照；载入场景会同步侧栏采样率；
- 页面给出采样后估计事件位置和定位误差，可保存基线 A 比较机制或采样间隔；CSV 保存当前空间剖面，文本报告保存输入、定位误差和模型边界；
- 四种机制（Rayleigh/OFDR、DAS、Brillouin、Raman）看同一个事件；
- “空间采样间隔”调大可看到峰被低估或漏掉——空间分辨率的直观演示；
- “四机制对比视图”并排展示四种曲线/热图；
- “Brillouin × Raman 温补解耦”：温度会伪装成应变（1 °C ≈ 22 με），用 Raman 测温度后从频移扣除，还原真实应变。

### ⑥ 分布式光学与数据 · 偏振与干涉

- **推荐场景**：偏振基线、横向应力、光纤扭转、温度交叉敏感和旋转与压力；选择后点击“载入光学场景”；
- 庞加莱球上的向量端点表示偏振态，页面同时给出 Stokes S1/S2/S3、方位角、椭圆率和温度引起的椭圆率偏移；
- EFPI 谱条纹随腔长变化，页面显示压力引起的有效腔长变化；Sagnac 区域显示输入角速度对应的相位差；
- “机制响应曲线与可辨识性”分开显示 Sagnac 的角速度—相位关系和 EFPI 的压力—腔长关系，避免把三种机制误认为同一测量链；
- 可保存当前为光学基线 A，再改变应力、扭转、温度、角速度或压力，使用同一张表比较当前 B；
- “双折射—扭转—温度联合视图”用网格图展示应力/扭转对偏振态的影响。

### ② FBG 基础与解调 · 解调与实验任务

- **推荐链路实验**：快速响应基线、阈值附近噪声、强滤波对照和温漂补偿；载入场景会同步弯曲角、噪声、窗口、阈值、温度与采样率；
- 三条曲线依次为原始、滤波、温补后的波长流；可调移动平均窗口和闭合控制阈值；
- 页面量化原始/滤波后噪声 RMS、理论滤波延迟、阈值裕量和逐采样指令一致率，用于比较降噪与响应速度；
- 可保存链路基线 A，再改变滤波窗口或阈值形成当前 B 对照；理论延迟不包含真实解调器、通信与执行器延迟；
- 下方多模态融合会综合抓取、足底、形状、健康、分布式质量，给出“任务就绪 / 需人工复核”；
- 八类实验任务分别显示三步操作提示，下载报告包含所选模块的完整当前记录与共享感知链摘要；冗余故障报告会区分注入通道与诊断通道。

### ④ 足底感知与装配 · 装配校验

- 页面顶部给出学习目标、建议操作、重点观察和模型边界；建议依次比较正常装配、压入不足与单侧错位；
- 传力场热图：亮区为传力集中处，错位时亮区中心横向偏移；
- 容差混淆矩阵：对角线越高越好，非对角格表示误判；
- 密封压缩率、预应变保持率是试验规划假设，不是寿命预测。

### ⑥ 分布式光学与数据 · 数据兼容

- 内置练习包括标准空白八列、带表头 CSV、列数不足和位置重复；后两项用于观察明确的拒绝原因；
- 合法数据会显示位置跨度、采样间隔范围/变异和八列最小—最大值，再提供标准化下载；
- 上传八列文本（最大 8 MB、最多 100,000 个有效采样行；可自动识别分隔符/跳过行数），检查通过后可下载标准化文本；
- 该页只做结构检查，不包含、不修改 FBG-SimPlus 源码。


### ⑦ 电子皮肤与多模态感知

- **系统总览与机制对照**：比较压阻、电容、压电/摩擦电、离子和 FBG 光学方案的观测量、适用任务与常见干扰；
- **三轴触觉单元**：调节 Fx/Fy/Fz、曲率、应变、温度、噪声和参考匹配度；页面显示五通道主动/参考/校正信号、三轴反演误差、矩阵秩和条件数；
- **FBG 光学皮肤**：选择 4/8/16 个传感点、单点/双点接触、感受野和温度；双点只评价合力和载荷质心，不声称唯一分离两个接触点；
- **稀疏压力重建**：从 4×4 或 8×8 采样重建 16×16 或 32×32 压力场，并同时检查 RMSE、峰值、质心、总载荷与通道节省率；
- **动态滑移与多模态**：比较六类时间序列，滑移告警比较记录 20% 后窗口内的剪切比峰值与质心速度绝对值峰值，两者均须越阈，但不要求同一时刻发生，并提供 20–200 次重复告警统计。离线速度计算含相邻采样，不是因果实时检测；“即将滑移”预设的剪切载荷随阈值生成，改阈值也会改变记录，不能当作固定记录上的独立阈值评估；
- 四个实验都可保存基线 A、下载 CSV 和 Markdown 报告。全部结果为可复现教学仿真，不能替代器件标定、实物测试或安全认证。

## 8. 常见问题

**Q：启动后页面空白/报错？**
先确认依赖装全：`python -m pip install -r requirements.txt`，再 `python -m streamlit run app.py`。

**Q：更新代码或重启服务后，如何确认页面恢复？**
更新 Python 模块后先停止并重新启动原预览服务一次，避免进程继续使用旧的导入缓存。本版修复了 pandas 并发导入导致图表初始化中断，以及直接点击标签时控件身份改变导致的回跳；已验证连续三次服务重启后旧页面重连、标签切换和参数联动。重启仍可能丢失仅保存在服务端会话中的基线 A、学习记录等，请在重启前下载需要保留的报告。若发生新的持续加载，先检查终端错误与服务是否仍在运行，不要反复启动多个占用同一端口的进程。

**Q：内嵌浏览器还会出现 MutationObserver.observe 非 Node 错误吗？**
本网站已将总览图、二维/三维抓取和十二组演示改为隔离文档，避免内嵌浏览器访问尚未就绪的同源 iframe。自动高度通过来源校验的消息同步，播放和全屏保持可用；当前环境的新页面验证没有该错误。没有修改浏览器安装包或屏蔽异常，因此不代表浏览器自身的注入问题已被修复，其他网站仍可能触发。若旧标签还在显示旧版内容，完成服务重启后再刷新。

**Q：跨页“下一步”按钮点了没反应？**
这些按钮使用 Streamlit 原生导航状态切换标签。若点击后仍未跳转，请刷新页面后重试，或直接点击顶部目标标签。

**Q：手部动作总是重播动画，拖动时卡卡的？**
在侧边栏关闭“平滑过渡动画（2D/3D 手）”，动作会直接跳变到当前姿态，不再重播过渡。

**Q：想换默认参数？**
侧边栏改好参数后，点“演示预设”之前的数值会保留在会话里；刷新页面会回到默认。

**Q：跑测试？**
```bash
python -m pytest tests -p no:cacheprovider
```

请在项目根目录、已激活 Python 环境且已安装 `requirements.txt` 后执行。该测试不依赖浏览器或网络，但要求 `fiber_robotics_sim/vendor/three.min.js` 等仓库文件完整可用。

### 拇指结构与测点观察器

在“③ 手部抓取与触觉 → 三维抓取”中，先用“三维一键握拳”或高级参数设定姿态，再打开“拇指测点观察器”。TH-L1 / TH-L2 对应原细分触觉 FBG 01 / 02；点击三维测点、标签、通道按钮或分行曲线可同步选择。可播放 2 秒规定闭合指令、拖动时间、恢复当前参数、旋转及复位视角，并控制外形、关节轴和测点显示。“模拟 FBG-02 缺测”仅影响观察器，缺测显示为灰色和无曲线，不记作零。

本例复用现有拇指胶囊几何及碰撞限制，MCP 局部 Y 负向、IP 局部 Z 正向。采样帧调用原抓取解析模型，末帧与当前参数一致；10 Hz、2 秒为展示指令时间，不是硬件采样或动力学结果。测点局部坐标、轴向、几何尺寸及两节均分触觉力为教学约定，需要真实 CAD、封装位置和标定数据才能用于实物。本例没有接入真实数据或增加资产依赖。

### 足底区域与通道观察器

在“④ 足底感知与装配 → 平衡与步态”查看六区位置与相位扫描。点击区域或使用“查看足底区域”下拉框，读取对应 FBG 的载荷、波长和相位曲线；点击曲线计算点可切换本页相位。位置为原模型归一化坐标，扫描固定其他条件，不是真实时间采样。侧栏模拟足底区域 1 失效后，该区显示灰色叉号和无有效反演载荷；保留替代波长供故障分析，但不将它当成零载荷观测。

### 三芯与沿程形状观察器

在“⑤ 形状与结构监测 → 连续体形状”查看新观察器。点击横截面的纤芯或用下拉框选取，读取对应波长和三芯去共模差分应变。点击沿程误差曲线上的计算节点，三维模型同步高亮参考与反演位置；节点滑杆可用键盘操作。可隐藏参考中心线、拖动旋转与双击复位三维视角。S-000～S-160 为原积分器输出的计算节点，并非沿长度的独立传感阵列；三芯读数只支持当前恒定曲率参数反演，扭转是已知先验。

### 结构测点与定位观察器

在“⑤ 形状与结构监测 → 结构健康”查看新观察器。点击梁段测点或超额应变曲线的通道，联动查看位置、波长、温补应变及相对阵列中位数的超额。ARM-N06-01 表示六点阵列的第一通道；改变阵列密度也会改变测点位置。橙色定位区间仅在原模型判定有效时显示，不是统计置信区间；紫色线为可隐藏的模拟异常设定。示意梁段不是实物 CAD，诊断不是裂纹确认或安全证明。

### 分布式位置与信号观察器

在“⑥ 分布式光学与数据 → 分布式感知”查看观察器。点击光纤位置或空间剖面的采样点，同步读取实际位置与观测值；也可使用“查看空间采样点”滑杆。D 编号代表轴向位置，不代表真实铺设路线。DAS 额外显示该位置的时间波形，并区分侧栏输入与原生成器实际时间步长；低采样率会提示混叠风险。Brillouin 沿用双源固定位置模型，不显示单事件定位。

### 光学皮肤测点与质心观察器

在“⑦ 电子皮肤与多模态感知 → 光学皮肤”查看新观察器。点击阵列 FBG 或通道曲线圆点，同步选取测点并读取局部位置、原始波长与温补波长；可隐藏模拟参考质心。下方表格解释每个模型接触分配到所选测点的权重，不是识别置信度。双点接触只评价载荷质心，不保证分离两个接触；零载荷下参考质心未定义。

### 压力重建位置观察器

入口：⑦ 电子皮肤与多模态感知 → 稀疏压力重建 → 压力重建位置观察器。

选择重建网格行，点击场图圆点或压力剖面节点，两图与数值卡同步到同一列。白色方框为模拟采样位置，圆点为插值计算节点；下方柱图解释每个采样通道对所选节点的加权贡献。改变核带宽或采样密度，观察峰值被平滑的程度。

位置为归一化坐标，未定义真实面积；显示的压力单位为 kPa，不能把节点压力直接相加当作牛顿。参考场和采样均为教学模拟，插值网格加密不等于增加传感器。

### 动态事件时刻观察器

入口：⑦ 电子皮肤与多模态感知 → 动态滑移与多模态 → 动态事件时刻观察器。点击信号曲线圆点或调整采样序号，查看同一时刻的力、剪切比、温度、质心位置与速度。可分别跳到剪切比峰值和速度峰值。

判定采用整段记录后 80% 窗口内的两个峰值，不要求同时越阈；选定时刻不代表告警发生时刻。低法向力的剪切比显示为未定义，温度不参与当前规则。位置仅为模型已有的一维质心示意。

### 三轴触觉通道观察器

入口：⑦ 电子皮肤与多模态感知 → 三轴触觉单元 → 三轴触觉通道观察器。点击通道关系图或电容曲线，同步查看该通道的主动、参考、校正信号，以及三轴灵敏度和反演贡献。

关系图按编号排布，不代表实物电极坐标。机械信号使用灵敏度矩阵正向计算，反演贡献使用同一矩阵的伪逆；负值为电容变化或代数贡献。五通道共同反演三轴力，当前模型不能替代实物标定。

### 压力重建对照实验

在稀疏压力重建页面展开“采样密度与带宽对照”。四组固定采用 4×4／8×8 采样和 0.08／0.24 带宽，噪声为零，共用当前场景、峰值参数与输出网格。先预测峰值损失，再比较参考峰值行剖面、采样峰值、重建峰值及全场 RMSE。

对照不改写主实验参数，不计算漏检率；4×4 与 8×8 的采样位置不是嵌套关系。当前高斯加权平均无法生成高于采样最大值的峰，网格加密不等于补回漏采的信息。

### 参考失配与校正对照实验

三轴触觉单元中展开“参考匹配度对照”。固定当前力、温度、曲率与应变，对比 80%、90%、100% 匹配度，分别显示无噪声与当前噪声结果。同组复用噪声样本，不代表重复实验统计。对照不改写主实验参数。

校正残差由未消除共模与主动／参考噪声之差组成。先观察完全匹配的无噪声结果，再将共模设为零，检查参考相减引入噪声的影响；不能将单个种子的最小误差当作实物最佳标定。

### 单点与双点可辨识性对照

在 FBG 光学皮肤中展开“同合力同质心对照”。比较中心单点与对称等载荷双点，调节间距并查看 4、8、16 通道响应。对照沿用尺寸、感受野和有效总载荷，固定无噪声且另设接触位置，不修改主实验。

四角对称阵列可能对两种分布给出相同响应；更多通道出现差异也不等于任意双点唯一可恢复。零间距为重合假设，零总载荷不定义质心。噪声尺度比较不作为检测阈值或识别率。

### 固定记录的噪声与阈值对照

动态滑移与多模态页面展开“动态判定对照”。固定生成端阈值 0.35，生成无噪声与当前噪声各 20 条记录，然后独立扫描判定阈值。切换对照阈值不生成新记录，也不改写主实验阈值。

表格解释剪切比、速度双条件及配对告警变化。结果属于有限模拟记录的规则告警率，没有真实滑移标签，不能解释为实测误报率、漏报率或识别准确率。

### 压力三维演示与节点联动

压力重建观察器的行、列选择会同步到上方已有三维演示。参考压力面和重建面以金色标记同一 GRID 节点，演示标题和说明给出编号及完整结果。播放仍只控制显示进度，重建标记随对应行显示；红色最大误差标记保留。

当前是观察器到三维演示的单向选择同步，三维画布不提供反向选点。网格切换会将越界选择限制到有效范围。

### 光学皮肤三维通道联动

观察器选择 FBG 后，上方原三维演示以白环标出该测点，信号栏对应行加白框，标题显示稳定编号。橙环仍表示估计质心。播放时白环跟随示意表面运动，文字显示动画帧的温补值；点击“当前参数”才与下方静态读数对照。当前是观察器到三维的单向选择同步。

### 动态观察器与三维时刻联动

动态事件观察器选取采样序号、曲线点或峰值后，上方已有三维演示自动定位同一原始采样帧。点击“观察器时刻”返回该帧；播放不会反向修改观察器。三维灯显示截至回放时刻的累计窗口判据，下方结果仍为整段记录判定。低法向力时剪切比显示未定义。

### 连续体形状节点与三维演示联动

形状重建观察器选择沿程节点后，上方已有三维演示在真实／重建中心线标出对应白色／金色点，粉线表示未放大的局部误差。标题沿用 S-编号，节点不是额外传感器。播放期间显示当前演示帧误差；点击“当前参数”与观察器对照。当前为观察器到三维的单向同步。

### 结构健康测点与三维联动

结构健康观察器选取测点后，上方已有梁体演示以白环标出相同轴向位置，并高亮信号行、显示 ARM 编号和动画帧波长。红环仍为异常设定，橙色区间仍为有效定位范围；选择测点不会产生或改变异常判断。播放期间不回写观察器，点击“当前参数”对照静态值。

### 足底区域与三维演示联动

足底观察器选区后，已有三维足底以白色矩形边框标记同一区域并高亮信号行。观察器曲线选取相位会同步主实验和三维当前参数帧。失效区域灰显，替代波长读数不代表零载荷；白点、橙环仍为 CoP 标记。播放不回写观察器，点击“当前参数”返回当前实验相位。

### 分布式观察器与演示位置联动

分布式感知观察器选择沿线采样位置后，原演示读取游标定位到同一点，标题显示 D-毫米位置编号；光纤上的紫色方标保持所选位置。播放只改变游标，点击“观察器位置”返回该点。方标不是异常定位，DAS 剖面仍表示时间窗最大振幅，Brillouin 不新增单事件定位。


### 三轴通道与受力演示联动

三轴触觉观察器选择 TAXEL-C 通道后，已有三维对照增加该通道的白色力贡献箭头与同单位读数。彩色箭头仍表示完整三轴力；白箭头使用原灵敏度矩阵伪逆计算的代数贡献，不表示电极独立受力或真实位置。五通道贡献相加才是校正总力。演示说明显示当前帧主动、参考和校正电容；点击“当前参数”与下方观察器对照。选择为观察器到演示的单向同步。


### 观察器与演示的统一操作

足底、连续体形状、结构健康、分布式感知，以及电子皮肤的四个实验，共八个入口提供“进入观察器”和“查看所选位置／通道的模型演示”页内链接。跳转不更改选择或实验参数；关闭演示后仍能使用观察器，再开启时恢复当前选择。当前为观察器到演示的单向联动，不提供共用演示内反向选点；拇指独立观察器保留已有双向选点。

共用演示支持拖动旋转，聚焦三维区域后可用方向键旋转、Home 复位、空格播放或暂停。“辅助网格”和有标签场景中的“部件标签”只控制辅助图层，不隐藏传感数据。没有部件标签的场景不显示该按钮。

读数条按本次完整演示的最大绝对值归一化，同一演示内共用比例，但不宜跨参数比较条长；负值保留负号。缺测显示“缺测 / 无有效观测”且不绘制条形；装配未就位、压力数据尚未显示分别保留各自的状态文字。足底失效通道的替代输入仍供原模型计算，但不作为有效测量展示。

动态模块点击“观察器时刻”返回所选原始采样帧；分布式模块点击“观察器位置”返回所选空间位置；其余模块点击“当前参数”对照静态结果。播放均不回写观察器。数据为教学模型生成，压力重建包含插值，不等同于真实测量或经验证的物理仿真。


二维、三维抓取现由 Streamlit 原生 iframe 承载，使用 data URL 保持独立来源；不再通过自定义组件主动删除 iframe，也不使用双画布预加载。模型与前后姿态保持原有逻辑；当前三维手臂过渡为 520 毫秒，手指过渡为 1000 毫秒。此变更恢复原生更新生命周期，仍需重算与加载，不等同于永久复用 WebGL 场景。其他模块的嵌入方式不变。


抓取性能：二维与三维抓取页的姿态、预设及任务按钮采用 Streamlit 局部刷新，只重算各自的抓取实验。公共参数或模块切换仍更新全页；抓稳状态通过会话状态同步至数据链路。局部刷新不改变模型、判定阈值或其他实验的计算。

### Blender 与结构数据协同

Blender 已融入光学皮肤、足底六区、足底装配和结构健康的原有演示，不另设独立试点。进入实验默认显示模型，点击“播放演示”或直接选择测点查看读数。光学皮肤通过“拆开看结构／合起结构”一键切换；曲线和技术详情按需展开。显示操作不改变实验计算。曲线横轴是演示进度，不是实测时间。制作、导出与模型边界见 [Blender 工作流](BLENDER_WORKFLOW.md)。
