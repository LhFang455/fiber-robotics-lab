# Blender 与实验模型的协同

Blender 用于编辑结构和层级；Python 保留传感计算；Three.js 根据稳定编号绑定数据和动画。Blender 无须部署到网站服务器，浏览器不执行 Blender。不是把视频嵌入页面，也不是用 Blender 物理引擎替代现有算法。

## 已融入的实验

| 实验位置 | 结构与数据的关系 |
| --- | --- |
| ⑦ / FBG 光学皮肤 | 承载层拥有 SKIN-Nxx-xx 测点。平面尺寸来自实验参数；分层展开与示意凹陷随动，不改变波长。 |
| ④ / 平衡与步态 | FOOT-Z1…6 部件分别绑定 SOLE-01…06 波长及区域载荷。失效区域保留无有效观测状态。 |
| ④ / 装配校验 | ASSEMBLY-L1…7 表示原装配层级，三个 FBG 均属于固定感知芯 ASSEMBLY-L6。就位前无有效读数。 |
| ⑤ / 结构健康 | ARM-Nxx-xx 测点附着于 HEALTH-BEAM。纵向位置仍采用原模型毫米坐标。 |

进入实验默认显示模型，常用操作是“播放演示”、选择测点和皮肤的“拆开看结构”。“查看变化曲线”与“技术详情与结构设置”按需展开；重播、速度和辅助图层收在“更多播放与显示选项”。模型下方直接显示“显示模型”开关，可随时隐藏或恢复模型。横轴为演示进度，不是实测时间；曲线中的断点保留缺测。演示内选中状态不回写下方静态观察器；白环为观察器选择，金框为演示内选择。皮肤可展开结构，所有信号仍来自原实验帧。

三轴力对照、稀疏压力重建、动态事件、连续体中心线、分布式扫描及光学数学视图保持程序生成。这些内容主要表达计算结果，不能为了使用 Blender 而伪造器件结构。二维与三维机械手未迁移，本次不触碰拇指 MCP 局部 Y 负向、IP 局部 Z 正向、抓取判定与过渡时长。

## 制作、编辑和导出

源文件：`fiber_robotics_sim/assets/lab_assets.blend`。四个集合 `skin / foot / assembly / health` 可单独显示和编辑；不要把它们叠加后的编辑工作区误认为一个物理装配。部件名称和自定义属性包含稳定编号、层级、角色及坐标保护信息。

- 在 Blender **编辑模式**中修改网格，保存源文件，然后导出；材质的基础颜色和透明度可修改。
- 原点、对象旋转/缩放、父子关系属于安装坐标契约。导出器遇到这些变更会停止，须先明确变更如何影响数据适配和测点，而不是随意应用变换。
- 当前运行时支持网格、法线、基础颜色和透明度，不承诺完整复制 Blender 材质节点、贴图或动画轨道。动画继续由原实验帧驱动。
- 网站不按顶点顺序绑定通道，不接受任意用户上传的 Blender 文件执行。

在项目目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender fiber_robotics_sim/assets/lab_assets.blend --background --python scripts/export_lab_assets.py
```

导出器读取已保存的源文件和修改器结果，校验后生成 `lab_assets.glb` 与 `lab_assets.json`，不重写 `.blend`。JSON 为当前轻量运行时，GLB 保留标准结构和自定义属性供后续复用。网页保留原程序模型作为资产校验失败时的回退，并给出可见提示。

只有确实要舍弃已有手工建模、从原参数化定义重建时才运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/generate_lab_assets.py -- --regenerate
```

生成器默认拒绝覆盖已存在的源文件。常规调整应使用导出器。

## 坐标与数据边界

网页资产为右手 Y-up；Blender 为 Z-up，转换为 `(x, y, z)_web = (x, z, -y)_Blender`。绑定具有 `id / part / local / normal / signal_index / readings`。`normal` 是安装法向，不是光纤轴向或已标定灵敏度方向。

健康梁的纵向坐标和皮肤的平面尺寸沿用原实验参数；层厚、支架、装配展开间距等仍是展示设置。足底示意空间与 CoP 的原仿射映射保留。皮肤连线是示意连接顺序，并非完成了弯曲半径、障碍与应变传递验证的走线设计。

本批网格由项目脚本原创生成，未导入厂商或第三方模型。不能据此称为真实 CAD、有限元分析、结构标定或全物理仿真。

## 验证

`tests/test_model_assets.py` 检查编号/父子关系/坏网格拒绝、GLB 元数据、局部坐标随动、缺失值与零值区分、原帧数据不变、信号和模型选择及曲线定位回调。

修改导出器或结构后运行相关模型测试，并在浏览器查看对应实验。自动化工具如果无法操作隔离 iframe，只能报告已完成显示检查与交互代码测试，不能声称实点交互已验证。
