# v0.3.0

本版本完成直观模型演示升级，提供面向参观、汇报和教学实验的统一演示体验。

## 本次更新

- 为十二个实验增加参数联动模型：足底步态、FBG 光学皮肤、连续体形状、足底装配、结构健康、FBG 温补、分布式剖面、材质触觉、偏振与干涉、动态滑移、三轴触觉和稀疏压力重建。
- 统一播放、暂停、重播、进度、速度、当前参数、视角复位和全屏操作，适配窄屏。
- 首页新增“3 分钟看懂光纤感知”：足底压力中心迁移、温度补偿、4×4/8×8 压力重建对照。采用独立固定参数，保留原实验状态。
- 明确分布式定位的有效条件与动态滑移的窗口判据，模型、图示和报告保持一致。
- 修复冷启动 pandas 导入竞争、标签导航状态、统计表显示与内嵌浏览器视图兼容问题。
- 更新用户指南，补充模型一致性、状态隔离、导航、嵌入视图和启动稳定性回归测试。

## 运行与验证

- 运行：`python -m streamlit run app.py`。
- 安装：`python -m pip install -r requirements-verified.txt`。
- 本地本期相关测试与关键流程视觉检查已执行；发布流程在 GitHub Actions 上再次运行 Ruff 和完整测试，仅通过后创建 Release。
- 详细操作见 `docs/USER_GUIDE.md`。

## 版本边界

模型用于教学与概念演示，示意形变、相位扫描和核插值结果不代表真实硬件或工程验收。三章成果演示为独立案例，不代表已接通的硬件系统。

版本名称与标签统一为 `v0.3.0`，旧标签 `v0.1.0`、`v0.2.0` 保留。后续开发基于本版本继续推进。
