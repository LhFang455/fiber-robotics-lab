# v0.2.0

本版本保存模块整合与电子皮肤实验完成后的教学网站，作为后续模型演示与动画改造的基线。

## 本次更新

- 将原有 13 个顶层模块整合到领域实验室，保留既有实验能力；新增电子皮肤领域后共 7 个顶层入口。
- 新增电子皮肤与多模态感知：三轴触觉、FBG 光学皮肤、稀疏压力重建、动态滑移与多模态判别，配有场景预设、对照、数据和报告导出。
- 丰富标定、解调、触觉识别、足底步态、装配校验、连续体形状、结构监测、分布式感知及偏振/干涉实验，补充参数解释、重复试验与结果评价。
- 完善六条引导式学习路线、独立进度记录、跨实验导航和三维抓取控制/图示布局。
- 补充输入检查、第三方使用说明、可复现依赖清单、完整自动化测试和 GitHub Actions 验证流程。

## 运行与验证

- 运行入口：`python -m streamlit run app.py`。
- 可复现环境：`python -m pip install -r requirements-verified.txt`。
- 验证命令：`ruff check app.py fiber_robotics_sim tests` 与 `python -m pytest tests -p no:cacheprovider`。
- 本 Release 仅在上述云端检查通过后创建。使用说明见仓库的 README 和 `docs/USER_GUIDE.md`。

## 版本边界

所有模型均用于教学与概念演示，不代表真实硬件性能、有限元验证或工程验收结论。后续新增的直观模型演示和动画不包含在本版本中。

旧版 `v0.1.0` 保留不变。本版本对应标签 `v0.2.0`，可从下方 Assets 下载源码 ZIP 或 tar.gz。
