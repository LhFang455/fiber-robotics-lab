## 第一批已确认方向与范围
面向上级和非专业参观者，在现有电子皮肤、足底步态、连续体形状实验中增加直观模型演示。保持七个领域入口、原参数控件、分析、导出和学习记录。本阶段在桌面活动项目的本地开发分支工作，不推送，不改动 v0.2.0。

## 页面与交互
演示面板放在对应实验开头，可用开关收起。桌面端模型、读数和讲解同屏；窄屏采用上下布局。播放器包含播放/暂停、重播、进度、速度、当前实验参数定位、复位视角和全屏。默认暂停，不在后台循环；拖动旋转，无滚轮缩放。页面不可见时暂停，尊重减少动态效果偏好。

## 三组演示
1. FBG 光学皮肤：一个或两个压头按压、横向移动、释放。FBG 光点颜色、波长和载荷来自 simulate_fbg_skin；初始停在当前参数的按压帧。表面凹陷仅表达接触，不作为压力重建或有限元位移；不引入无依据的滑移风险判定。
2. 足底步态：保持当前地形、载荷、支撑状态、噪声和失效设置，扫描支撑相位 0–100%，展示六区载荷与 CoP 由脚跟向前掌迁移。当前相位单独定位。支撑期扫描不冒充完整行走动力学；低载荷/失效标注可靠性，零载荷不显示无定义 CoP。
3. 连续体形状：曲率从 0 增长到当前输入，保持方向、已知扭转先验、噪声和芯间温差。用实体管状模型和重建轮廓展示三芯波长、中心线 RMSE 与末端误差；实际几何坐标和误差不放大，管径为可视化示意。

## 实现边界
- Python 生成离散参数扫描帧，前端只负责播放，不每帧重跑 Streamlit。
- 使用现有 NumPy、Streamlit 和本地 Three.js，无 CDN 或新增依赖。
- demos.py 负责数据适配与 HTML 装配；demo_scene.html 负责独立播放器；demo_views.py 负责缓存和 Streamlit 入口。app.py 仅增加三个插槽和渲染调用，不重构实验。
- 同一帧的读数、模型状态、讲解同步。无定义数值输出 null，序列化禁止 NaN/Infinity。
- 固定每次扫描的随机种子用于对照；播放时间是讲解进度，不是物理时间或动态噪声采样。

## 稳定性问题修复（2026-09-04，接续收尾）
- 冷启动导入竞争：隔离浏览器在首次渲染时快速切换模块，真实复现 Plotly 读取未完成初始化的 pandas，报 `AttributeError: ... pandas ... has no attribute Series`。增加冷进程并发导入回归测试，先失败后通过；应用在渲染任何控件前显式完成 pandas 导入，重复统计表使用 DataFrame，计算公式不变。
- 标签回跳：Streamlit 的 tabs 默认值参与控件身份计算，原实现直接点击标签后改变 default，导致同一组标签被重建。新增测试先证明身份发生变化，再修复为直接点击时保持 default 不变，仅显式导航请求修改 default/版本；注册后同步实际标签值。保留七领域和各子实验、目录按钮与场景跳转。
