# 实验室导航整合与电子皮肤模块设计

日期：2026-09-02

## 目标

先将现有 13 个顶层模块收束为 6 个领域实验室，在不删减既有实验、下载、状态与教学内容的前提下降低导航分散度；随后新增第 7 个“电子皮肤与多模态感知”领域实验室，使其具备完整的机制认知、传感建模、重建分析、动态判别和实验导出能力。

## 约束

- 只修改当前网站需要的文件，不顺带重构无关代码。
- 保留现有模型、Streamlit 状态键、下载内容和实验能力。
- 不执行 git add、commit、push、tag 或 release。
- 仅在关键流程进行网页视觉检查：顶层导航、手部整合页、电子皮肤页。
- 新模块的数值结果标明为教学仿真，不冒充实测性能或论文复现结果。
- 不引入新的第三方依赖，也不复制外部项目代码或素材。

## 阶段一：六个领域实验室

顶层导航调整为：

1. 系统总览
2. FBG 基础与解调
3. 手部抓取与触觉
4. 足底感知与装配
5. 形状与结构监测
6. 分布式光学与数据

各领域内部保留原实验：

- FBG 基础与解调：弯曲标定与温补、冗余诊断与接触反演、实时解调与控制报告。
- 手部抓取与触觉：二维抓取、三维抓取、材质识别与重复采样。
- 足底感知与装配：步态与压力中心、通道失效、空载装配与密封公差。
- 形状与结构监测：连续体形状重建、点式阵列异常定位。
- 分布式光学与数据：分布式感知、偏振/Sagnac/EFPI、FBG-SimPlus 数据兼容。

导航采用两层结构：顶层只显示领域实验室，领域内使用子标签切换实验。引导路线记录“领域 + 子实验”，避免依赖原来的 13 个数字位置。原有实验代码保持原执行顺序，以避免控制报告对前序结果的依赖断裂。

## 阶段二：电子皮肤与多模态感知

新增第 7 个顶层实验室，包含五组相互关联的教学内容：

1. **系统总览与机制对照**：介绍压阻、电容、压电/摩擦电、离子与 FBG 光学方案的信号来源、适用动态、常见干扰和教学边界。
2. **三轴触觉单元**：输入法向力、切向力、曲率、应变、温度、噪声和参考匹配度；展示五通道主动信号、参考信号、校正信号、力反演误差、矩阵秩和条件数。
3. **FBG 光学皮肤**：配置 4/8/16 个传感点、皮肤尺寸、感受野、单点或双点接触、温度和噪声；展示传感路径、波长响应、压力质心、载荷与定位误差。
4. **稀疏压力重建**：从 4×4 或 8×8 采样重建 16×16 或 32×32 压力场；提供单点、双点、边缘接触和滑动前兆情景，并报告 RMSE、峰值误差、质心误差、总载荷误差和通道节省率。
5. **动态滑移与多模态决策**：生成稳定按压、载荷爬升、横向滑动、即将滑移、热物体和温漂等时间序列；展示压力、剪切、质心速度、温度、阈值裕度及告警结果，并支持重复试验统计。
